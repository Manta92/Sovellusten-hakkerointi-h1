## h1

### a1) What is included

  My household network infrastructure is quite small and simple. It has a modem and two laptops. Both are firewall protected. All accounts and virtual machines used are protected by passwords or multifactor authentication. A cell phone is occasionally used to share a network connection if the wi-fi is down.

  - The primary laptop I use on this course has a virtual Linux server
  - Study related accounts: Moodle, GitHub

### a2) What is excluded

  - The secondary laptop, it has a Snapdragon processor that is incompatible with the course requirements
  - Nothing else to exclude, single household with no additional devices

### a3) Key interfaces and boundaries

  - Study related accounts: Moodle, GitHub
  - SSH connection on Linux server
  - Internet service provider: DNA oy
  - Cloud services in use: Google Drive and OneDrive
